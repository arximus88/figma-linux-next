# Frontend Design

This skill guides the creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

## Design Thinking

Before coding, commit to a BOLD aesthetic direction:
- **Tone:** Pick an extreme (e.g., brutally minimal, maximalist, retro-futuristic, luxury, playful, brutalist).
- **Differentiation:** Identify one unforgettable element.

**CRITICAL:** Choose a clear conceptual direction and execute it with precision.

## Aesthetic Guidelines

### Typography
Choose beautiful, unique fonts. Avoid generic fonts like Arial, Inter, or Roboto. Pair a distinctive display font with a refined body font.

### Color & Theme
Commit to a cohesive palette. Use CSS variables. Dominant colors with sharp accents are preferred.

### Motion
Use animations for effects and micro-interactions. Prioritize CSS-only solutions for simple effects. Use libraries like Motion for React for complex orchestrations.

### Spatial Composition
Use unexpected layouts: asymmetry, overlap, diagonal flow, or grid-breaking elements.

### Backgrounds & Visual Details
Add depth with gradient meshes, noise textures, geometric patterns, layered transparencies, dramatic shadows, or grain overlays.

## What to Avoid
- **Generic AI Aesthetics:** Overused font families (Inter, Roboto), cliched color schemes (purple gradients on white), and cookie-cutter component patterns.
- **Indecision:** Mixing conflicting aesthetic directions.

**IMPORTANT:** Match implementation complexity to the aesthetic vision. Maximalist designs need elaborate code; minimalist designs need restraint and precision.
