figma-linux-next

Unofficial Figma desktop client for Linux — Flatpak repository. Current release: v__VERSION__.

Install with one click (GNOME Software / KDE Discover open .flatpakref files directly)

Or from the terminal

flatpak install --user https://__HOST__/__PATH__/figma-linux-next.flatpakref

To add the repository only, so updates arrive with flatpak update:

flatpak remote-add --user --if-not-exists figma-linux-next \
    https://__HOST__/__PATH__/figma-linux-next.flatpakrepo
flatpak install --user figma-linux-next app.borys.FigmaLinuxNext

Every commit and the repository summary are signed with the key __FPR__; it is embedded in the .flatpakrepo file and also published as figma-linux-next-repo.gpg.

Source, release notes and other installers (deb, rpm, AppImage, AUR, Nix): github.com/arximus88/figma-linux-next. Not affiliated with or endorsed by Figma, Inc.
