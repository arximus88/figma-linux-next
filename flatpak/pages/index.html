Flatpak repository

Figma Linux Next v__VERSION__

An unofficial Figma desktop client for Linux. Install from this signed repository to receive updates through Flatpak.

Install the app

Open the Flatpak reference with GNOME Software or KDE Discover.

Install with one click

Install from the terminal

This adds the repository and installs the app.

Terminal
flatpak install --user https://__HOST__/__PATH__/figma-linux-next.flatpakref

Add the repository manually

Use these commands if you prefer to add the remote yourself.

Terminal
flatpak remote-add --user --if-not-exists figma-linux-next \
  https://__HOST__/__PATH__/figma-linux-next.flatpakrepo
flatpak install --user figma-linux-next app.borys.FigmaLinuxNext

The repository is signed with key __FPR__. The key is included in the .flatpakrepo file and available as figma-linux-next-repo.gpg.
